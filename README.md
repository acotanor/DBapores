# Steam Recommender con Flask

## Instalación

```bash
python -m venv .venv
pip install -r requirements.txt
```

## Ejecución

```bash
# Correr la aplicación
python run.py # Lanza el servidor en localhost:5000
# Generar o Regenerar la caché
python scripts/generar_cache.py # Ejecuta la configuración por defecto
python scripts/generar_cache.py -h # Muestra un mensaje de ayuda con las opciones de ejecución
```
